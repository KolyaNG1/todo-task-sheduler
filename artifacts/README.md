# Переносимые артефакты приложения

Каталог предназначен для всех изменяемых данных планировщика. Его устройство и
правила описаны в [системном дизайне бэкенда](../BACKEND_DESIGN.md).

## Структура

- `database/` — живая SQLite и её временные WAL/SHM-файлы;
- `backups/` — согласованные резервные копии базы;
- `portable/` — готовые для переноса снимки с манифестом и контрольными суммами;
- `exports/` — пользовательские выгрузки JSON и CSV;
- `imports/` — входящие, обработанные и отклонённые импорты;
- `attachments/` — будущие пользовательские вложения;
- `logs/` — ограниченные по размеру технические журналы;
- `agent_runs/` — будущие изолированные материалы запусков агента;
- `tmp/` — очищаемые промежуточные файлы.

Содержимое этих папок не попадает в Git. Служебные `.gitkeep` сохраняют саму
структуру в чистой копии проекта.

## Перенос

Весь каталог можно копировать только при остановленном приложении. Во время
работы следует создавать согласованный снимок в `portable/`, потому что свежие
изменения SQLite могут находиться в WAL-файле.

Не храните здесь ключи, пароли и токены внешних сервисов.
