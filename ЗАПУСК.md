# Самостоятельный запуск

Дважды нажмите [Запустить планировщик.bat](<Запустить планировщик.bat>). Он
сразу запустит сервер и интерфейс, затем откроет `http://127.0.0.1:3000/`.

Файл ничего не скачивает и не устанавливает. Он предполагает, что Python и
библиотеки проекта уже есть на компьютере.

Данные остаются в каталоге `artifacts/`. Его можно скопировать на другой
компьютер вместе с проектом, чтобы перенести свою базу.

Чтобы остановить приложение, закройте окна «Планировщик — сервер» и
«Планировщик — интерфейс» в диспетчере задач либо перезапустите компьютер.
