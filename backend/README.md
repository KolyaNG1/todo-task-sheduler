# Серверная часть планировщика

Сервер реализован на Python и FastAPI. Браузер, Telegram-бот и будущий сценарий
Codex CLI используют одинаковые прикладные сервисы; HTTP является только первым
входным адаптером.

Для обычного запуска всего приложения из корня проекта достаточно дважды
нажать `Запустить планировщик.bat`. Файл не устанавливает пакеты: он использует
уже установленный Python. Подробности — в [инструкции запуска](../ЗАПУСК.md).

## Быстрый запуск

Из каталога `backend/`:

```powershell
python -m pip install --no-build-isolation -e ".[dev]"
python -m uvicorn planner.main:app --reload --port 8000
```

После запуска документация методов доступна на `http://127.0.0.1:8000/docs`.
База создаётся в `../artifacts/database/planner.sqlite3`. Для хранения данных в
другом месте задайте переменную `PLANNER_ARTIFACTS_DIR` абсолютным путём.

## Проверки

```powershell
python -m pytest
```

## Устройство

- `domain/` — чистые правила: интервалы, приоритеты и алгоритм планирования;
- `application/` — сценарии создания задач, календаря, плана и таймера;
- `infrastructure/` — SQLite, файлы артефактов и настройки;
- `api/` — HTTP-преобразование запросов и ответов;
- `migrations/` — история схемы SQLite.

Полная целевая архитектура описана в
[`../BACKEND_DESIGN.md`](../BACKEND_DESIGN.md).
