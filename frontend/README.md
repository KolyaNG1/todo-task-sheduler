# Фронтенд планировщика

Статический интерфейс первой версии. Он использует API по адресу
`http://127.0.0.1:8100/api/v1` и не содержит предметной логики или доступа к
SQLite.

## Локальный запуск

Из корня рабочей области:

```powershell
python -m http.server 3000 --directory frontend
```

Затем откройте `http://127.0.0.1:3000`. Серверная часть должна работать на
порту 8100. Адрес API можно изменить в пункте «Сервер» левой навигации.
Сохранённые локальные адреса с устаревшим портом автоматически заменяются на
`http://127.0.0.1:8100/api/v1`; при неудачном подключении к пользовательскому
адресу интерфейс один раз пробует штатный локальный адрес.

## Первый срез

Реализованы главный недельный экран, выбор задач, создание задач, рабочее время
на дату, неподвижные события, предварительное планирование, применение безопасных
блоков и управление рабочей сессией. Остальные разделы навигации будут развиты
следующими срезами.
