# Фронтенд планировщика

Статический интерфейс первой версии. Он использует API по адресу
`http://127.0.0.1:8000/api/v1` и не содержит предметной логики или доступа к
SQLite.

## Локальный запуск

Из корня рабочей области:

```powershell
python -m http.server 5173 --directory frontend
```

Затем откройте `http://127.0.0.1:5173`. Серверная часть должна работать на
порту 8000. Адрес API можно изменить в пункте «Сервер» левой навигации.

## Первый срез

Реализованы главный недельный экран, выбор задач, создание задач, рабочее время
на дату, неподвижные события, предварительное планирование, применение безопасных
блоков и управление рабочей сессией. Остальные разделы навигации будут развиты
следующими срезами.
