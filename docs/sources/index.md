# Каталог источников

[← К оглавлению](../index.md)

Источники — первичные материалы: требования, статьи, спецификации, датасеты,
внешняя документация и значимые результаты экспериментов. Исходный материал не
переписывается ради согласования с выводом агента; исправляется вывод.

Для важного источника создайте карточку по
[шаблону](../templates/source.md), укажите путь или адрес, дату доступа,
происхождение и связанные задачи.
