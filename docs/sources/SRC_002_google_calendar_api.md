# SRC_002 — Официальные материалы Google Calendar API о доступе и синхронизации

[← К каталогу источников](index.md)

## Происхождение

- Автор или владелец: Google.
- Дата публикации или создания: действующая документация Google for Developers.
- Дата доступа: 2026-09-22.
- Путь или адрес: [OAuth 2.0 для серверного приложения](https://developers.google.com/identity/protocols/oauth2/web-server), [добавочная синхронизация](https://developers.google.com/workspace/calendar/api/guides/sync), [уведомления об изменениях](https://developers.google.com/workspace/calendar/api/guides/push).

## Содержание

Документы описывают получение пользовательского разрешения, сохранение маркера
синхронизации после первичной выгрузки, обработку добавочных изменений и
уведомления, которые доставляются на HTTPS-адрес приложения.

## Область применимости и ограничения

- Подтверждают возможности официального API Google Календаря.
- Не определяют предметные правила планировщика: направление обмена, поведение
  при конфликте и состав экспортируемых данных выбирает проект.
