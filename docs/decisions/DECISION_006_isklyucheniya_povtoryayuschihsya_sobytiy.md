# DEC_006 — Исключения повторяющихся событий по локальной дате

[← К журналу решений](index.md)

## Контекст

Правка или удаление события из одного дня не должна незаметно менять всю
еженедельную серию. В то же время календарь, доступное время и конфликты
должны читать одинаковый результат для выбранной даты.

## Рассмотренные варианты

- Копировать правило в каждую неделю: увеличивает объём данных и ломает
  связь с серией.
- Менять одно правило для всех дат: нарушает ожидаемое действие в плане.
- Хранить отдельные исключения: сохраняет правило и адресность изменения.

## Решение

У пары «правило + локальная дата» может быть одно исключение с изменёнными
полями либо признаком отмены. По умолчанию действия из плана обращаются к
этому исключению; галочка явно обращается к правилу серии. Правка серии
заменяет локальные изменения видимых повторов, но оставляет ранее отменённые
даты. Все расчёты используют итоговое событие на конкретную дату.
