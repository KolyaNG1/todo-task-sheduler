# DEC_007 — Общий порядок корневых проектов и групп

[← К журналу решений](index.md)

## Контекст

Отдельные полноширинные секции групп растягивали проекты и не позволяли
расположить папку рядом с обычной карточкой. Пользователю нужны плитки,
подобные папкам приложений.

## Рассмотренные варианты

- Оставить два независимых списка: нет единого перетаскивания.
- Создать новую таблицу позиций плиток: усложняет данные без необходимости.
- Переиспользовать позиции проекта и группы: сохраняет совместимость.

## Решение

Корневые проекты и группы имеют общий порядок `position`; вложенные проекты
имеют независимый порядок внутри группы. Сервер проверяет полную перестановку
плиток. Интерфейс ограничивает ширину карточки проекта и показывает группу
компактной папкой, раскрывающейся на две плитки.

## Основания и доказательства

- [TASK_056 — реализация и измерения интерфейса](../tasks/TASK_056_sdelat_gruppy_proektov_kompaktnymi_peretaskivaemymi_plitkami/056_concl.md).

## Последствия

Дополнительной таблицы нет. Старые запросы изменения раскладки без общего
порядка принимаются для совместимости, новые передают `root_items`.
