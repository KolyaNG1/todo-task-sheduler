Календарный ползунок и размещение индикатора дня исправлены.

## Подтверждённые результаты и доказательства

- Ползунок работает с шагом в один день в диапазоне года назад и вперёд.
- Семидневное окно начинается с выбранного дня, поэтому соседние недели
  перекрываются шестью днями при одном шаге ползунка.
- Индикатор находится в нормальном потоке страницы над сеткой без внешнего
  отступа и плавающего позиционирования.

## Полезные наблюдения

- Принудительное выравнивание API по понедельнику несовместимо с плавным
  календарным просмотром.
