# TASK_004 — Подключить пользовательский MCP API Google к Codex

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./004_logs.md)
- [Выводы](./004_concl.md)

## Цель

Определить, какие сведения нужны для подключения пользовательского MCP-сервера
Google к Codex, и дать безопасную схему настройки для локального клиента.

## Границы

### Входит

- Проверка официальных ограничений и вариантов подключения MCP к Codex.
- Подготовка перечня параметров, которые пользователь должен сообщить.

### Не входит

- Фактическое подключение без адреса сервера и способа авторизации.
- Передача, хранение или публикация секретов.

## Требования пользователя

- 2026-09-08 — исходный запрос: «крч у меня есть mcp api к google switch. Как научить тебя к нему подключаться?».
- 2026-09-08 — пользователь сообщил сервер `https://stitch.googleapis.com/mcp` и заголовок `X-Goog-Api-Key`; реальное значение ключа в чат не передавалось.
- 2026-09-09 — принято решение использовать Stitch MCP для подготовки интерфейса, а Codex — для написания фронтенда в коде проекта.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [x] Определена разница между подключением MCP и обучением модели.
- [x] Зафиксированы необходимые параметры и ограничения текущей сессии.
- [x] Выводы и глобальное знание обновлены.
- [x] Зафиксирован рабочий процесс создания фронтенда через Stitch MCP и Codex.
- [ ] Пользователь предоставил параметры сервера для конкретной настройки.
- [ ] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Проверить официальные сведения о MCP в Codex.
2. Отделить общую схему от параметров конкретного Google-сервера.
3. Запросить только безопасные сведения, необходимые для настройки.
4. Обновить локальную и глобальную документацию.

## Допущения и ограничения

- Название «Google Switch» не позволяет однозначно определить продукт или адрес сервера.
- Пользовательский фрагмент содержит Markdown-ссылку внутри URL и требует отдельной TOML-строки для заголовка.
- Токены, ключи и файлы с секретами не нужны для предварительной консультации и не должны присылаться в чат.
