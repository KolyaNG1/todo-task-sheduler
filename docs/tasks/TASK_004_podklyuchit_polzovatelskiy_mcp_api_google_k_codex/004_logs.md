## L-20260908-01 — Задача создана

**Событие:** создана задача «Подключить пользовательский MCP API Google к Codex».

**Основание:** новый самостоятельный запрос или исследование.

**Следующий шаг:** уточнить цель, критерии завершения и существующие знания.

## L-20260908-02 — Проверены официальные сведения о MCP

**Событие:** изучены официальные материалы OpenAI о пользовательских MCP-приложениях и плагинах.

**Результат:** MCP подключается как внешний сервер/приложение с описанными инструментами и авторизацией; это не обучение модели. Для конкретной настройки нужны адрес или команда запуска, транспорт и способ входа.

**Ограничение:** изменение локальной конфигурации не добавляет инструмент в уже запущенную текущую сессию автоматически; локальный клиент обычно нужно обновить или перезапустить, а доступ должен быть разрешён в самом клиенте/рабочем пространстве.

## L-20260908-03 — Получен адрес Stitch и проверен локальный конфиг

**Событие:** пользователь передал адрес `https://stitch.googleapis.com/mcp` и имя заголовка `X-Goog-Api-Key`, скрыв значение ключа.

**Проверка:** в `%USERPROFILE%\\.codex\\config.toml` уже есть локальный сервер `node_repl`, блока `stitch` нет. Секретные строки не выводились.

**Решение:** безопасный фрагмент должен использовать обычный URL без Markdown-разметки, отдельный заголовок TOML и строковое значение ключа. Фактический ключ пользователь подставляет локально.

## L-20260908-04 — Добавлен блок Stitch в локальный конфиг

**Событие:** в `C:\\Users\\Kolya\\.codex\\config.toml` добавлен блок `[mcp_servers.stitch]` с адресом сервера и меткой вместо секрета.

**Проверка:** блок записан на строках 136–140; настоящий ключ не передавался и не сохранялся агентом.

**Следующий шаг:** пользователь заменяет `<ВСТАВЬ_КЛЮЧ_СЮДА>` на локальный ключ и перезапускает Codex.

## L-20260908-05 — Уточнён способ открытия файла

**Событие:** пользователь сообщил, что VS Code показывает пустой файл.

**Проверка:** фактический файл `C:\\Users\\Kolya\\.codex\\config.toml` существует, имеет размер 4355 байт, содержит настройки Codex и блок Stitch на строках 136–140.

**Вывод:** ссылка с суффиксом номера строки могла открыться как новая пустая вкладка. Пользователю нужно открыть именно полный путь к существующему файлу через `Ctrl+O` или командой `code "C:\\Users\\Kolya\\.codex\\config.toml"`.

## L-20260909-06 — Stitch проверен реальным MCP-запросом

**Событие:** сервер Stitch зарегистрирован штатной командой `codex mcp add stitch --url https://stitch.googleapis.com/mcp`.

**Проверка:** `codex mcp list` показывает сервер как `enabled`; MCP `initialize` вернул HTTP 200 без ошибки авторизации; `tools/list` вернул HTTP 200 и 15 инструментов.

**Результат:** соединение, ключ и выдача инструментов работают. Перезапуск Codex нужен, чтобы текущий рабочий сеанс подхватил обновлённый список инструментов.

## L-20260909-07 — Зафиксирован процесс разработки фронтенда

**Решение:** Stitch MCP используется для создания и изменения экранов, вариантов интерфейса и дизайн-системы; Codex использует эти материалы для написания и изменения фронтенд-кода в проекте.

**Ограничение:** Stitch MCP сам по себе не заменяет работу Codex с файлами проекта и не является самостоятельной системой сборки приложения.
