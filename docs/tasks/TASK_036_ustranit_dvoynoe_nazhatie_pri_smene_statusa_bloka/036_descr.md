# TASK_036 — Устранить двойное нажатие при смене статуса блока

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./036_logs.md)
- [Выводы](./036_concl.md)

## Цель

Убрать двойное нажатие и задержку отрисовки при завершении и повторном открытии
задачи из календарного блока.

## Границы

### Входит

- Единый локальный статус задачи для карточек и блоков.
- Мгновенная отрисовка состояния до фоновой синхронизации с сервером.

### Не входит

- Изменение данных пользователя или семантики дедлайнов.

## Требования пользователя

- 2026-09-12 — исходный запрос: Устранить двойное нажатие при смене статуса блока.


## Критерии завершения

- [x] Выполнение меняет визуальный статус блока с первого нажатия.
- [x] Повторное открытие снимает серое оформление с первого нажатия.
- [x] Проверки и документация обновлены.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Найти два разных статуса, по которым рисуется блок.
2. Связать визуальное состояние с актуальным статусом задачи.
3. Применять обновление локально до фонового перечитывания.
4. Проверить и зафиксировать результат.

## Допущения и ограничения

- Серверный статус остаётся источником истины; локальное изменение только
  устраняет видимую задержку до ответа фоновой синхронизации.

## Уточнения наследуемого контекста

- Если задача дочерняя, перечислите только уточнения и допустимые
  переопределения. Остальной контекст читается из задач-предков.

## Рассмотренные варианты и обоснования

- Вместо повторного обращения по клику введена одна функция локальной
  синхронизации статуса задачи и блоков; её используют оба направления
  жизненного цикла.
