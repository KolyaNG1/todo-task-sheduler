## L-20260914-02 — Найдена причина неполного запуска

**Событие:** API не запускался на 8000: Windows отклонил привязку с `WinError
10013`, поскольку 8000 попадает в текущий исключённый диапазон 7966–8065.

**Доказательство:** ручной запуск Uvicorn на 8000 завершился с ошибкой; тот же
сервер на 8100 успешно ответил `200` на `/api/v1/health`.

## L-20260914-03 — Усилен сценарий запуска

**Событие:** API переведён на 8100. bat сперва проверяет уже работающие API и
интерфейс, а затем при необходимости запускает их и ждёт готовность с помощью
`scripts/wait_for_planner.py`.

**Доказательство:** 3000 и 8100 ответили `200`; повторный запуск не добавил
новых слушателей портов. Файл bat переведён на CRLF, требуемые для корректного
исполнения `cmd.exe` на этой машине.
