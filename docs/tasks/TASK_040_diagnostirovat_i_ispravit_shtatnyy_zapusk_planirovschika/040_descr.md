# TASK_040 — Диагностировать и исправить штатный запуск планировщика

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./040_logs.md)
- [Выводы](./040_concl.md)

## Цель

Сделать двойной щелчок по `Запустить планировщик.bat` надёжным: не открывать
интерфейс без API, не использовать запрещённый Windows порт и не плодить
процессы при повторном запуске.

## Границы

### Входит

- Диагностика текущего запуска и портов Windows.
- Выбор доступного порта API и обновление клиентского адреса.
- Ожидание готовности API и интерфейса перед открытием браузера.
- Защита от повторного создания процессов при уже работающем приложении.

### Не входит

- Завершение чужих процессов и изменение системных резервов портов Windows.

## Требования пользователя

- 2026-09-14 — исходный запрос: Диагностировать и исправить штатный запуск планировщика.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [x] API запускается на доступном порту, а интерфейс использует его по умолчанию.
- [x] bat ждёт доступности обоих адресов и сообщает о неуспехе.
- [x] Повторный запуск не создаёт новые серверы, если оба уже отвечают.
- [x] Выводы и глобальные знания обновлены.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Проверить текущий bat, доступность портов и причину отказа API.
2. Перевести API на доступный порт и синхронизировать клиент.
3. Добавить ожидание готовности и защиту от повторного запуска.
4. Проверить ответы API и интерфейса, обновить документацию.

## Допущения и ограничения

- Приложение использует уже установленный системный Python: проектное окружение
  не содержит серверных библиотек.

## Уточнения наследуемого контекста

- Если задача дочерняя, перечислите только уточнения и допустимые
  переопределения. Остальной контекст читается из задач-предков.

## Рассмотренные варианты и обоснования

- Не менять системные резервирования Windows: выбран свободный API-порт 8100.
- Не хранить сложную проверку готовности в строке bat: она была чувствительна к
  синтаксису командной оболочки. Ожидание вынесено в стандартный Python-скрипт.
