## L-20260914-02 — Найдена и устранена ошибка формата bat

**Событие:** выявлены смешанные переводы строк в `Запустить планировщик.bat`:
часть строк была в CRLF, часть — в LF. Это нарушало разбор команд Windows и
могло оставить интерфейс без API.

**Действие:** весь файл приведён к CRLF. После запуска API на `8100` и
интерфейс на `3000` ответили кодом `200`; обновлённая вкладка показала данные
планировщика вместо ошибки подключения.

**Следующий шаг:** завершить задачу после проверки документации.
