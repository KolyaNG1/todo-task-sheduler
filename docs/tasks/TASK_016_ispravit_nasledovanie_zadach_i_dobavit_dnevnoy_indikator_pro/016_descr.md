# TASK_016 — Исправить наследование задач и добавить дневной индикатор прогресса

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./016_logs.md)
- [Выводы](./016_concl.md)

## Цель

Сделать создание задач согласованным с направлениями и добавить понятную обратную связь о продуктивности текущего дня.

## Границы

### Входит

- Наследование оценки, важности и цвета при выборе направления.
- Любая положительная целая оценка в минутах.
- Личный цвет задачи без направления.
- Завершение задачи прямо с блока расписания с сохранением блока.
- Дневной индикатор по работе, заполненности плана и завершённым задачам.

### Не входит

- Переработка алгоритма планирования, кроме совместимой проверки длительности из TASK_015.

## Требования пользователя

- 2026-09-10 — при выборе направления задача должна наследовать время, важность и другие видимые настройки; оценка не ограничивается шагом 15 минут; задача без направления получает свой цвет; выполненную задачу можно отметить в расписании без удаления блока; нужен игровой индикатор успеха дня из трёх метрик.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [x] Результат задачи получен и проверен.
- [x] Выводы и проблемы описаны.
- [x] Глобальные знания обновлены.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

1. Уточнить область и существующие знания.
2. Выполнить работу или исследование.
3. Проверить результат.
4. Обновить локальную и глобальную документацию.
