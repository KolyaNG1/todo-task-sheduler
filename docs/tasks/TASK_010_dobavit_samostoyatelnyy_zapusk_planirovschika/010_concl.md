# Выводы TASK_010 — Добавить самостоятельный запуск планировщика

[← К описанию](./010_descr.md) · [Журнал](./010_logs.md)

## Краткий итог

Добавлен двойным щелчком запускаемый файл для Windows. Он делает первый запуск
самостоятельным, а затем открывает приложение по локальному адресу.

## Подтверждённые результаты и доказательства

- **Подтверждено:** запускатор создаёт `.venv` только при отсутствии, ставит
  зависимости из `backend`, проверяет Python 3.13+ и записывает журналы в
  `artifacts/logs`.
- **Подтверждено:** запускатор не создаёт второй процесс для портов 8000 и
  5173, ожидает готовность API и только затем открывает интерфейс.

## Полезные наблюдения

- Для самостоятельного запуска достаточно одного файла в корне; данные остаются
  в `artifacts/` и не затрагиваются запускатором.

## Проблемы и преграды

- Автоматическая установка на первом запуске зависит от доступа к интернету и
  установленного Python 3.13+; понятные сообщения направляют пользователя к
  причине сбоя.

## Как решались проблемы

- Запускатор использует локальное виртуальное окружение, чтобы не менять
  системные пакеты Python пользователя.
