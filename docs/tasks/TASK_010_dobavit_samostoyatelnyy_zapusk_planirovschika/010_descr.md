# TASK_010 — Добавить самостоятельный запуск планировщика

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./010_logs.md)
- [Выводы](./010_concl.md)

## Цель

Добавить для Windows один запускаемый файл, который самостоятельно готовит
окружение при первом старте, поднимает сервер и интерфейс и открывает браузер.

## Границы

### Входит

- Файл `Запустить планировщик.bat` в корне проекта.
- Автоматическая подготовка локального окружения Python и установка зависимостей
  только при первом запуске.
- Защита от повторного запуска серверов на уже занятых портах.

### Не входит

- Упаковка в автономный исполняемый файл без установленного Python.

## Требования пользователя

- 2026-09-09 — исходный запрос: Добавить самостоятельный запуск планировщика.
- 2026-09-09 — пользователь попросил `.bat`-файл, который запускается как
  приложение и сам открывает сервис.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [x] Запускаемый файл создаёт среду, запускает оба сервера и открывает браузер.
- [x] Первый запуск объясняет установку зависимостей, последующие не дублируют
  серверы на уже занятых портах.
- [x] Результат задачи получен и проверен статически.
- [x] Выводы и проблемы описаны.
- [x] Глобальные знания обновлены.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Проверить актуальные команды запуска и требования Python.
2. Создать безопасный запускаемый файл и краткую инструкцию.
3. Проверить команды, кавычки и уже работающие сервисы.
4. Обновить документацию.

## Допущения и ограничения

- Windows и Python 3.13+ установлены; для первого запуска доступен интернет.
