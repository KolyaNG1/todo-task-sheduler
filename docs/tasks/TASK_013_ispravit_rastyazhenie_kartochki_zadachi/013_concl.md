# Выводы TASK_013 — Исправить растяжение карточки задачи

[← К описанию](./013_descr.md) · [Журнал](./013_logs.md)

## Краткий итог

Карточки задач больше не растягиваются на свободную высоту списка.

## Подтверждённые результаты и доказательства

- **Подтверждено:** `.task-list` сохраняет гибкую высоту для прокрутки, но
  выравнивает строки к началу, поэтому единичная карточка остаётся компактной.
- **Проверка:** страница после обновления показала одну активную задачу как
  отдельную карточку с нормальным набором действий.

## Полезные наблюдения

- У гибкого контейнера с CSS-сеткой нужно явно указывать выравнивание
  содержимого, если его строки не должны занимать всё свободное место.

## Проблемы и преграды

- Нет.

## Как решались проблемы
