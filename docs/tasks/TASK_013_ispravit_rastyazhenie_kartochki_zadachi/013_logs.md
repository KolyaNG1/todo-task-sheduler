## L-20260909-02 — Растяжение строки отключено

**Событие:** у сетки списка задач добавлено выравнивание содержимого к началу.

**Причина:** гибкая высота списка и значение по умолчанию растягивали одну
строку сетки на всё свободное пространство.

**Проверка:** после обновления страницы список отобразил единственную активную
задачу отдельной карточкой, а не пустой растянутой областью.
