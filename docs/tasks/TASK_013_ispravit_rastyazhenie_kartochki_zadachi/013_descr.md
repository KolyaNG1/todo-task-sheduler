# TASK_013 — Исправить растяжение карточки задачи

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./013_logs.md)
- [Выводы](./013_concl.md)

## Цель

Исправить растяжение единственной карточки задачи на всю высоту левой панели.

## Границы

### Входит

- Запрет растягивания строк списка задач по свободной высоте.
- Проверка загрузки страницы с одной задачей.

### Не входит

- Изменение данных задачи и планировщика.

## Требования пользователя

- 2026-09-09 — исходный запрос: Исправить растяжение карточки задачи.
- 2026-09-09 — пользователь показал, что единственная задача стала высокой на
  весь список после исправления панели выбора.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [x] Карточки остаются нормальной высоты при свободном месте в списке.
- [x] Результат задачи получен и проверен.
- [x] Выводы и проблемы описаны.
- [x] Глобальные знания обновлены.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Найти изменение, растягивающее сетку списка.
2. Зафиксировать строки сетки в начале области.
3. Проверить страницу с одной активной задачей.
4. Обновить документацию.

## Допущения и ограничения

- Свободная высота прокручиваемой области не должна передаваться карточкам.

## Уточнения наследуемого контекста

- Если задача дочерняя, перечислите только уточнения и допустимые
  переопределения. Остальной контекст читается из задач-предков.

## Рассмотренные варианты и обоснования

Сохраняйте краткие причины выбора, альтернативы и проверяемые допущения, но не
скрытое пошаговое рассуждение модели.
