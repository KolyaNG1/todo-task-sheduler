# TASK_023 — Исправить немедленное отображение блоков автоплана

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./023_logs.md)
- [Выводы](./023_concl.md)

## Цель

После подтверждения автоплана новые блоки должны без клика появляться в нужных
днях календаря и не исчезать из-за фонового обновления.

## Границы

### Входит

- Диагностика последовательности «применить автоплан → обновить календарь».
- Защита локально добавленных, перенесённых и удалённых блоков от устаревшего
  снимка календаря.
- Проверка синтаксиса, серверных тестов и локального запуска.

### Не входит

- Изменение алгоритма выбора времени для автоплана.
- Перепроектирование интерфейса календаря.

## Требования пользователя

- 2026-09-10 — исходный запрос: Исправить немедленное отображение блоков автоплана.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [x] Блок остаётся в модели календаря сразу после ответа на применение плана.
- [x] Устаревший ответ фонового обновления не может затереть новое действие.
- [x] Проверены синтаксис интерфейса, серверные тесты и локальный запуск.
- [x] Выводы и проблемы описаны.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Сопоставить локальное изменение с фоновой синхронизацией.
2. Внести защиту от пересечения запросов и временно сохранить блок до
   подтверждения сервером.
3. Проверить результат и запуск.

## Допущения и ограничения

- Полная синхронизация остаётся фоновой, чтобы действия с блоками были
  мгновенными; задержка перед ней не является единственной защитой.

## Уточнения наследуемого контекста

- Если задача дочерняя, перечислите только уточнения и допустимые
  переопределения. Остальной контекст читается из задач-предков.

## Рассмотренные варианты и обоснования

- **Решение:** хранить краткий список ещё не подтверждённых изменений блоков
  в браузере. При получении старого снимка он накладывается поверх снимка, а
  новое чтение запускается повторно. Это надёжнее, чем просто увеличить
  задержку перед повторным запросом.
