# Выводы TASK_023 — Исправить немедленное отображение блоков автоплана

[← К описанию](./023_descr.md) · [Журнал](./023_logs.md)

## Краткий итог

Исправлено исчезновение свежего блока после применения автоплана: он
отображается сразу и остаётся видимым до подтверждения сервером.

## Подтверждённые результаты и доказательства

- **Причина:** `applyPlan` добавлял блок в локальный календарь, но сразу после
  этого запускал чтение полного снимка. При пересечении запросов снимок мог
  быть получен до фиксации новой записи в SQLite и заменял локальный календарь
  без нового блока.
- **Исправление:** интерфейс помечает только что добавленный, перенесённый или
  удалённый блок ожидающим подтверждения. При приходе снимка он накладывает
  такие изменения поверх данных сервера, пока сервер не вернёт тот же блок или
  его отсутствие. Ответ, начатый до более нового действия, игнорируется.
- **Проверка:** `node --check frontend/app.js` завершился успешно; `pytest`
  завершился с результатом `8 passed`; локальные API и интерфейс ответили
  `200`, интерфейс загрузил календарь и блоки в браузере.
