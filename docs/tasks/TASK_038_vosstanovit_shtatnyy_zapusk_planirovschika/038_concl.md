## Краткий итог

Штатный запуск восстановлен.

## Подтверждённые результаты и доказательства

- Windows резервирует диапазон 5151–5250, включая прежний 5173; Python не мог
  привязать к нему сервер интерфейса.
- Скрипт использует свободный 3000 и открывает `http://127.0.0.1:3000/`.
- Задержка запуска использует `ping`, поэтому не даёт ошибку перенаправления
  ввода в неинтерактивном окружении.
- Проверены ответы 200 от интерфейса и API, а также загрузка данных в браузере.

## Полезные наблюдения

- Нельзя возвращать интерфейс на 5173, пока Windows резервирует этот диапазон;
  изменение резервирования не требуется для работы приложения.
