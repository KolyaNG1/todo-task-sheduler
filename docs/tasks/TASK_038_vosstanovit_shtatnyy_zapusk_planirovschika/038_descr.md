# TASK_038 — Восстановить штатный запуск планировщика

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./038_logs.md)
- [Выводы](./038_concl.md)

## Цель

Восстановить запуск планировщика двойным щелчком по `Запустить планировщик.bat`.

## Границы

### Входит

- Диагностика отказа локального интерфейсного сервера.
- Выбор доступного порта и обновление ссылки запуска.
- Проверка доступности интерфейса и API после запуска.

### Не входит

- Изменение резервирования портов Windows или сетевых настроек системы.

## Требования пользователя

- 2026-09-12 — исходный запрос: Восстановить штатный запуск планировщика.


## Критерии завершения

- [x] Скрипт использует свободный порт интерфейса.
- [x] После запуска доступны API на 8000 и интерфейс на 3000.
- [x] Документация и проверки обновлены.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Проверить порты и текст запускающего файла.
2. Заменить занятый системный диапазон на совместимый порт.
3. Запустить скрипт и проверить HTTP-ответы.

## Допущения и ограничения

- API уже разрешает запросы интерфейса с порта 3000.

## Уточнения наследуемого контекста

- Если задача дочерняя, перечислите только уточнения и допустимые
  переопределения. Остальной контекст читается из задач-предков.

## Рассмотренные варианты и обоснования

- Выбран порт 3000: 5173 входит в зарезервированный Windows диапазон, а 3000
  уже разрешён политикой доступа API.
