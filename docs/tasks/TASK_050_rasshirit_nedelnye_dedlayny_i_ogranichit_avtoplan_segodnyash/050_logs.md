## L-20260921-02 — Реализованы расчёты и интерфейс

**Событие:** недельный снимок дополнен подробными дедлайнами и расчётом

текущего момента. Редактор календарного блока объединён со стандартными полями
задачи, а время блока переведено на минутную точность.

**Доказательства:** добавлены два интеграционных сценария для недельной нагрузки,
вычитания уже размещённого времени, ограничения автоплана и отказа для полностью
прошлого диапазона.

## L-20260922-03 — Проверена живая сборка

**Событие:** обнаружен и остановлен прежний процесс сервера на порту 8100,
который продолжал отдавать старую схему ответа. Планировщик повторно запущен
штатным `Запустить планировщик.bat`.

**Доказательства:** живой API вернул недельную нагрузку и подробные дедлайны;
в браузере показаны сводка, раскрывающийся список дедлайнов и объединённый
редактор. Поле конца блока приняло `12:50` при шаге 60 секунд; тестовое изменение
было отменено. Дополнительная проверка выявила остаточное серверное требование
15-минутной границы; оно удалено для ручного создания и изменения блоков и
закреплено отдельным сценарием `06:10–07:10` → `06:20–07:20`. В консоли
браузера ошибок нет. Полный набор — 34 успешных теста.
