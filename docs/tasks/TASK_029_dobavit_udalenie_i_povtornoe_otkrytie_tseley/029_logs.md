## L-20260911-02 — Добавлен жизненный цикл целей

**Событие:** добавлены серверные маршруты повторного открытия и удаления цели,
а также кнопки списка и страницы цели.

**Решение:** удаление является мягким и отвязывает все задачи от цели. Задачи,
их дерево, блоки расписания и история сессий не изменяются.

**Проверка:** автоматический тест проверяет последовательность «создать →
завершить → вернуть в активные → удалить» и сохранность задачи. Набор содержит
20 успешно прошедших тестов; новый API после перезапуска вернул `200` на
проверке здоровья и содержит оба маршрута в описании интерфейса.
