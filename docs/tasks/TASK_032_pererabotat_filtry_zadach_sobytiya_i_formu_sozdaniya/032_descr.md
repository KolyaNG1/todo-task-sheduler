# TASK_032 — Переработать фильтры задач, события и форму создания

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./032_logs.md)
- [Выводы](./032_concl.md)

## Цель

Сделать управление задачами и неподвижными событиями понятным, предсказуемым и
компактным: явно различать обычные задачи, чекпоинты и группы, не терять время
события при редактировании и улучшить читаемость коротких блоков расписания.

## Границы

### Входит

- Фильтры типов «Задачи», «Чекпоинты» и «Цели» в левой панели и более
  компактная отдельная страница задач.
- Явная кнопка автопланирования для конечного чекпоинта.
- Редактирование и удаление неподвижного события только через его кнопки;
  сохранение исходных времени и даты в форме.
- Счётчик сроков в шапке каждого дня расписания.
- Исправление размещения кнопки добавления, коротких блоков и формы задачи.
- Ясное редактирование родительской связи: дочерняя задача является
  чекпоинтом, но остаётся полноценно редактируемой.

### Не входит

- Изменение модели целей и иерархии данных за пределами нужных интерфейсных
  пояснений и фильтров.

## Требования пользователя

- 2026-09-12 — исходный запрос: добавить фильтры «Задачи», «Чекпоинты»,
  «Цели»; исправить редактирование неподвижного события; улучшить короткие
  блоки, индикаторы сроков, кнопку «+», страницу задач и форму создания.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [x] Все заявленные действия доступны без случайного открытия события.
- [x] В форме события отображаются сохранённые дата и время.
- [x] В шапке дня отображается число сроков этого дня.
- [x] Результат задачи получен и проверен.
- [x] Выводы и проблемы описаны.
- [x] Глобальные знания обновлены.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

3. Проверить результат.
4. Обновить локальную и глобальную документацию.
