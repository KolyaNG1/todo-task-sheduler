# Выводы TASK_031 — Исправить прокрутку и жизненный цикл задач в интерфейсе

[← К описанию](./031_descr.md) · [Журнал](./031_logs.md)

## Краткий итог

Исправлены независимая прокрутка банка задач, ручной перенос срока задачи,
доступные удаления и наложения управляющих элементов. Локальный сервис
перезапущен и отвечает.

## Подтверждённые результаты и доказательства

- Банк задач больше не растягивает страницу: `.app-shell` ограничен высотой
  окна, у `.task-list` свой вертикальный скролл. Проверка в браузере: 510 px
  видимой высоты при 1750 px содержимого.
- При ручном перетаскивании и редактировании блока клиент отправляет
  `move_task_deadline: true`. Сервер переносит срок задачи на конец блока и
  закрывает открытые уведомления `OVERDUE`; 21 тест, включая регрессионный
  сценарий, завершился успешно.
- Уже перенесённый ранее блок «БЖД» также приведён в согласованное состояние:
  срок задачи — 15.09.2026 11:45 по Москве, уведомление о просрочке закрыто.
- Кнопка «Удалить задачу» показана в форме существующей задачи. Вложенные
  задачи дерева цели имеют крестик для мягкого удаления; корневой узел имеет
  крестик «Убрать из цели», который не удаляет данные.
- Кнопки восстановления скрытых панелей перенесены к нижнему краю экрана,
  поэтому не пересекаются с верхней панелью календаря. Карточки целей используют
  18 px заголовок и непереносящиеся короткие кнопки.

## Полезные наблюдения

- Серверная политика переноса срока должна быть явной: `move_task_deadline`
  передаётся только при пользовательском ручном переносе, а не при любом
  изменении блока из интеграций.
- Локальная карточка задачи обновляется сразу после ответа изменения блока;
  это не даёт старому сроку оставаться на экране до фоновой загрузки.

## Проблемы и преграды

- Автоматическое обнаружение старого переноса, совершённого до появления
  признака `move_task_deadline`, не выполняется намеренно: нельзя отличить его
  от блоков, для которых исходный срок менять не следует.

## Как решались проблемы

- Для уже старого блока пользователь может открыть его карандашом и сохранить
  время: это применит новую политику и перенесёт срок без изменения длительности.
