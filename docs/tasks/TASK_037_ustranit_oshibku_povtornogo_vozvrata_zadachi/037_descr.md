# TASK_037 — Устранить ошибку повторного возврата задачи

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./037_logs.md)
- [Выводы](./037_concl.md)

## Цель

Сделать возврат задачи и её блока в расписание безопасным при повторном нажатии
и при данных, где завершён только интервал.

## Границы

### Входит

- Идемпотентный серверный возврат задачи.
- Регрессионный тест отдельного завершённого блока.

### Не входит

- Изменение даты, срока или фактического времени задачи.

## Требования пользователя

- 2026-09-12 — исходный запрос: Устранить ошибку повторного возврата задачи.


## Критерии завершения

- [x] Возврат не выдаёт ошибку для активной задачи с завершённым блоком.
- [x] Регрессионный тест добавлен.
- [x] Документация и проверки обновлены.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Сопоставить статус задачи и статус интервала.
2. Разрешить повторный возврат для активной задачи.
3. Добавить проверку старого состояния данных.

## Допущения и ограничения

- Повторный возврат не должен менять уже подтверждённый активный блок.

## Уточнения наследуемого контекста

- Если задача дочерняя, перечислите только уточнения и допустимые
  переопределения. Остальной контекст читается из задач-предков.

## Рассмотренные варианты и обоснования

- Маршрут возврата сделан идемпотентным, чтобы один и тот же интерфейсный
  вызов корректно обрабатывал оба допустимых состояния.
