# Выводы TASK_037 — Устранить ошибку повторного возврата задачи

[← К описанию](./037_descr.md) · [Журнал](./037_logs.md)

## Краткий итог

Ошибка «Вернуть в активные можно только завершённую задачу» устранена для
состояния, когда завершён блок, а задача уже активна.

## Подтверждённые результаты и доказательства

- `reopen_task` принимает активную или завершённую задачу и возвращает её
  завершённые блоки в `CONFIRMED`.
- Добавлен тест сценария «активная задача + завершённый блок».

## Полезные наблюдения

- Статус задачи и статус интервала могут различаться в исторических данных;
  возврат должен приводить их к совместимому активному состоянию.

## Проблемы и преграды

- Не обнаружены.

## Как решались проблемы

- Использован повторяемый безопасный серверный переход вместо ошибки.
