# TASK_030 — Исправить переполнение кнопок в карточках целей

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./030_logs.md)
- [Выводы](./030_concl.md)

## Цель

Исправить переполнение кнопок жизненного цикла за границы карточек целей.

## Границы

### Входит

- Компактные действия «Открыть», «Готово/Вернуть», «Удалить» в карточке цели.
- Три одинаковые колонки действий без горизонтального переполнения.

### Не входит

- Изменение серверных маршрутов жизненного цикла цели.

## Требования пользователя

- 2026-09-11 — исходный запрос: Исправить переполнение кнопок в карточках целей.
- 2026-09-11 — приложен снимок: кнопки «Вернуть в активные» и «Удалить»
  вышли за границы карточки цели.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [x] Действия карточки занимают только её ширину и не переполняют её.
- [x] Результат задачи получен и проверен.
- [x] Выводы и проблемы описаны.
- [x] Глобальные знания и решения обновлены.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Проверить разметку и правило раскладки действий.
2. Задать независимую трёхколоночную раскладку действий цели.
3. Проверить отсутствие переполнения в чистой вкладке.
4. Обновить документацию.

## Допущения и ограничения

- На карточке показываются короткие подписи; полное действие «Вернуть в
  активные» доступно на странице конкретной цели и как подсказка кнопки.

## Уточнения наследуемого контекста

- Если задача дочерняя, перечислите только уточнения и допустимые
  переопределения. Остальной контекст читается из задач-предков.

## Рассмотренные варианты и обоснования

- **Решение:** не надеяться на автоматический перенос строк во flex-контейнере.
  Для карточки цели задана собственная сетка из трёх равных колонок.
