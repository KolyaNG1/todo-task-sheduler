# TASK_039 — Скрывать панель показателей и убирать архивные задачи из плана

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./039_logs.md)
- [Выводы](./039_concl.md)

## Цель

Сделать верхнюю сводку плана управляемой панелью и исключить архивированные
задачи из текущего расписания без потери возможности восстановления.

## Границы

### Входит

- Кнопка скрытия и восстановления верхней сводки на странице плана.
- Исключение архивных задач из серверной выдачи недели и защитная фильтрация во
  фронтенде.
- Постоянное мягкое выделение воскресенья в календаре.
- Проверки клиентского кода и серверного сценария архивации.

### Не входит

- Изменение архива, восстановления и окончательного удаления сущностей.
- Изменение состава показателей верхней сводки.

## Требования пользователя

- 2026-09-12 — исходный запрос: скрывать всю панель показателей; при переносе
  задачи в архив убирать её с плана.
- 2026-09-12 — уточнение: слегка затемнять заголовок воскресенья на каждой
  неделе.
- 2026-09-12 — уточнение: показатели дня и цели в верхней сводке должны быть
  на одном горизонтальном уровне, без самопроизвольного переноса.
- 2026-09-12 — повторное уточнение по скриншоту: горизонтальная строка должна
  сохраняться и при текущей ширине окна; воскресенье должно быть заметно
  выделено; архивирование из списка задач должно сразу убирать блок с сетки.
- 2026-09-12 — повторное уточнение: прошлое исправление не отразилось в
  браузере; нужна жёсткая двухколоночная сводка и защита от кэша стилей.
- 2026-09-12 — уточнение: воскресенье не должно выглядеть зелёным; выделение
  должно быть нейтральным и более тёмным.
- 2026-09-12 — уточнение: крестик должен быть единственным для объединённой
  панели показателей и целей, а воскресенье нужно затемнить ещё сильнее.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## План

1. Проверить текущую сводку плана, выдачу недели и сценарий архивации.
2. Добавить состояние скрытия сводки с восстановлением.
3. Отфильтровать архивные задачи в выдаче недели и интерфейсе.
4. Добавить воскресную подсветку, тест и обновить документацию.

## Допущения и ограничения

- Блоки архивированных задач не удаляются физически: это нужно для
  восстановления из архива.

## Уточнения наследуемого контекста

- Если задача дочерняя, перечислите только уточнения и допустимые
  переопределения. Остальной контекст читается из задач-предков.

## Рассмотренные варианты и обоснования

Сохраняйте краткие причины выбора, альтернативы и проверяемые допущения, но не
скрытое пошаговое рассуждение модели.

- Восстановление сводки вынесено в панель управления, поскольку скрытая панель
  не может содержать собственную кнопку.
- Фильтрация сделана и в серверном запросе, и в клиенте: сервер не считает
  архивные блоки занятостью, а клиент не рисует устаревшие данные при гонке
  обновления.
