# TASK_055 — Разделить изменение повторяющегося события на день и серию

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./055_logs.md)
- [Выводы](./055_concl.md)

## Цель

Изменение и удаление повторяющегося события непосредственно в недельном плане
по умолчанию затрагивают только выбранную дату. Пользователь может явно
поставить галочку, чтобы применить действие ко всей серии.

## Границы

### Входит

- Исключение для одной даты повторяющегося события: изменение содержимого или
  отмена показа, без изменения остальных повторов.
- Явный выбор «Применить ко всем повторам» при редактировании и удалении
  повторяющегося события из плана.
- Совместимое хранение исключений и их учёт во всех расчётах календаря.
- Серверные и интерфейсные проверки одиночного повтора и серии.

### Не входит

- Правила сложных повторений (например, каждый второй вторник).

## Требования пользователя

- 2026-09-26 — исходный запрос: Разделить изменение повторяющегося события на день и серию.
- 2026-09-26 — удаление и изменение из плана по умолчанию действуют только в
  выбранном дне; отдельная галочка применяет действие ко всем повторам.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [x] Правка одного повторения сохраняет остальные дни без изменений.
- [x] Удаление одного повторения скрывает только его дату и освобождает время.
- [x] Галочка меняет или архивирует всю серию.
- [x] Данные переживают перезапуск, а расчёты свободного времени учитывают
  исключение.
- [x] Результат задачи получен и проверен.
- [x] Выводы и проблемы описаны.
- [x] Глобальные знания и решения обновлены.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Добавить модель исключения повторения и серверные действия для одной даты.
2. Подключить явный выбор области изменения в календарном интерфейсе.
3. Проверить изменение, удаление, серию и сохранность прочих дат.
4. Обновить журнал, выводы и знания проекта.

## Допущения и ограничения

- Исключение прикрепляется к исходному правилу и локальной дате; редактирование
  одной даты не может незаметно перенести повторение на другой день.
- Изменение всей серии не стирает ранее заданные исключения отдельных дат.

## Уточнения наследуемого контекста

- Если задача дочерняя, перечислите только уточнения и допустимые
  переопределения. Остальной контекст читается из задач-предков.

## Рассмотренные варианты и обоснования

- Выбрана отдельная таблица исключений по `(правило, дата)`. Новое разовое
  событие вместо исключения не сохраняло бы явную связь с серией, поэтому
  последующие изменения и удаление серии стали бы неоднозначными.
