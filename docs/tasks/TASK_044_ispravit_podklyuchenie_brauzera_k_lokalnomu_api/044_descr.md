# TASK_044 — Исправить подключение браузера к локальному API

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./044_logs.md)
- [Выводы](./044_concl.md)

## Цель

Устранить `Failed to fetch` в обычном браузере, если в его локальном хранилище
остался старый адрес API, и дать пользователю проверенную рабочую ссылку.

## Границы

### Входит

- Нормализация сохранённого локального адреса API.
- Резервная попытка подключения к штатному адресу `8100`.
- Обновление версии клиентского файла для обхода старого кэша браузера.
- Проверка через интерфейс с намеренно установленным портом `8000`.

### Не входит

- Изменение пользовательских данных и публикация сервиса в интернете.

## Требования пользователя

- 2026-09-14 — после запуска `.bat` окно исчезает, а обычный браузер на `3000`
  продолжает показывать `Failed to fetch`; нужна рабочая ссылка.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [x] Старые локальные адреса автоматически заменяются на порт `8100`.
- [x] Клиент повторяет неудачное подключение через штатный адрес.
- [x] Новая версия `app.js` принудительно запрашивается браузером.
- [x] Проверка с портом `8000` завершилась загрузкой 20 задач и расписания.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Сопоставить состояние API с ошибкой в обычном браузере.
2. Исправить миграцию сохранённого адреса и резервное подключение.
3. Обновить версию подключаемого клиентского файла.
4. Проверить ошибочный порт через форму и открыть рабочую ссылку.

## Допущения и ограничения

- Локальный сервис работает на `127.0.0.1`; произвольный внешний адрес в
  настройках сохраняет поддержку ручного подключения.

## Уточнения наследуемого контекста

- Если задача дочерняя, перечислите только уточнения и допустимые
  переопределения. Остальной контекст читается из задач-предков.

## Рассмотренные варианты и обоснования

- Ошибка могла сохраняться только в одном браузере, поскольку `localStorage`
  (локальное хранилище браузера) раздельно для разных браузеров.
- Любой сохранённый адрес `localhost` или `127.0.0.1` теперь считается адресом
  штатного локального сервиса и переводится на `8100`.
