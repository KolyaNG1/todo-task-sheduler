## L-20260914-02 — Исправлено сохранённое подключение браузера

**Событие:** сервер и интерфейс отвечали, но ошибка могла оставаться в обычном
браузере из-за его отдельного сохранённого адреса API и старой версии скрипта.

**Действие:** добавлена нормализация локального адреса на `8100`, резервное
подключение к штатному адресу и новая версия ссылки на `app.js`.

**Проверка:** через форму сервера намеренно выбран `8000`; клиент автоматически
вернулся на `8100` и показал 20 задач. Рабочая ссылка открыта и оставлена
пользователю.
