# TASK_012 — Исправить перекрытие панели выбора задач

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./012_logs.md)
- [Выводы](./012_concl.md)

## Цель

Убрать перекрытие недельного расписания панелью выбора задач и оставить
действия «Запланировать» и «Снять» доступными в пределах списка задач.

## Границы

### Входит

- Перенос панели выбора в обычный поток левой панели.
- Проверка её фактического положения в браузере.

### Не входит

- Изменение алгоритма автоматического планирования.

## Требования пользователя

- 2026-09-09 — исходный запрос: Исправить перекрытие панели выбора задач.
- 2026-09-09 — пользователь сообщил, что широкая плашка выбора перекрывает
  расписание и делает недоступными «Запланировать» и «Снять».

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [x] Панель выбора остаётся внутри списка задач и не может перекрыть сетку.
- [x] Результат задачи получен и проверен в браузере.
- [x] Выводы и проблемы описаны.
- [x] Глобальные знания обновлены.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Найти правило позиционирования панели выбора.
2. Перевести её в поток левой панели.
3. Проверить вычисленное положение в браузере.
4. Обновить документацию.

## Допущения и ограничения

- Панель выбора должна быть компактной частью банка задач, а не наложением на
  недельную сетку.

## Уточнения наследуемого контекста

- Если задача дочерняя, перечислите только уточнения и допустимые
  переопределения. Остальной контекст читается из задач-предков.

## Рассмотренные варианты и обоснования

Сохраняйте краткие причины выбора, альтернативы и проверяемые допущения, но не
скрытое пошаговое рассуждение модели.
