# TASK_052 — Преобразовать изображение PNG в значок ICO для Windows 11

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./052_logs.md)
- [Выводы](./052_concl.md)

## Цель

Преобразовать предоставленный PNG-файл с пиксельным изображением пальмы в
многослойный значок `.ico`, пригодный для назначения значком приложения в
Windows 11.

## Границы

### Входит

- Проверка исходного PNG и сохранение его прозрачности.
- Создание ICO с несколькими стандартными размерами, включая 256×256.
- Проверка структуры полученного файла и наличия всех слоёв.
- Сохранение готового файла в рабочей области; при наличии прав — копия рядом
  с исходным изображением на рабочем столе.

### Не входит

- Изменение рисунка, удаление фона или перерисовка изображения.
- Установка значка в конкретное приложение или изменение ярлыков Windows.

## Требования пользователя

## Критерии завершения

- [x] Результат задачи получен и проверен.
- [x] ICO содержит размеры 16, 24, 32, 48, 64, 128 и 256 пикселей.
- [x] Выводы и проблемы описаны.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Проверить исходный PNG и доступные средства преобразования.
2. Создать многослойный ICO без изменения рисунка.
3. Проверить размеры слоёв и читаемость файла.
4. Обновить документацию и выполнить проверку рабочей области.

## Допущения и ограничения

- Исходное изображение не редактируется; меняется только контейнер формата.
- Для значка Windows 11 используются стандартные размеры от 16 до 256 пикселей.

## Уточнения наследуемого контекста

## Рассмотренные варианты и обоснования

Выбран многослойный ICO, а не один растровый слой: Windows сможет выбрать
подходящий размер для ярлыка, панели задач и проводника.
