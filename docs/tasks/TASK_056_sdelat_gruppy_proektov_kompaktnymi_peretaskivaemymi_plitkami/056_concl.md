# Выводы TASK_056 — Сделать группы проектов компактными перетаскиваемыми плитками

[← К описанию](./056_descr.md) · [Журнал](./056_logs.md)

## Краткий итог

Группы представлены компактными папками-плитками в общей сетке с проектами.
Корневые проекты и группы можно переставлять между собой, сохраняя порядок.

## Подтверждённые результаты и доказательства

- Отдельные карточки проекта имеют 250 пикселей, раскрытая группа — около
  514 пикселей, вложенные карточки — около 238 пикселей на широком экране.
  Измерено в живом браузере; полноширинного растяжения нет.
- Сервер проверяет, что новая раскладка содержит каждую группу и каждый проект
  ровно один раз; неверная раскладка отвергается. `pytest backend/tests`: 36
  успешно.

## Полезные наблюдения

- Один корневой порядок хранится в уже существующих `position` проекта и
  группы; внутри группы `position` проекта локален. Старый запрос раскладки без
  `root_items` остаётся совместимым.
- Связанные знания: [интерфейс](../../knowledge/informatsionnaya_arkhitektura_interfeysa.md),
  [база данных](../../knowledge/baza_dannyh_planirovschika.md).

## Проблемы и преграды

- В текущем окне встроенного браузера доступна узкая область просмотра,
  поэтому ширина подтверждена измерением элементов при широком контрольном
  размере и проверкой снимка узкого окна; реальное перетаскивание мышью в этом
  сеансе не проверено.

## Как решались проблемы

- Разделён перенос проекта внутрь группы и перенос самой группы среди
  корневых карточек; вложенный проект имеет приоритет при начале перетаскивания.
