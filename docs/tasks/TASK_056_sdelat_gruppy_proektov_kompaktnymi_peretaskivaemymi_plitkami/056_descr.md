# TASK_056 — Сделать группы проектов компактными перетаскиваемыми плитками

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./056_logs.md)
- [Выводы](./056_concl.md)

## Цель

Группы проектов и отдельные карточки живут в общей сетке. Группа выглядит как
компактная папка с миниатюрами проектов; её можно перетаскивать между карточками,
а раскрытие не растягивает проекты на всю страницу.

## Границы

### Входит

- Единый сохраняемый порядок корневых карточек и групп.
- Компактная плитка группы, раскрытие и перенос проектов между группами.
- Проверка ширины карточек на широком и узком экране.

### Не входит

- Новая иерархия групп внутри групп.

## Требования пользователя

- 2026-09-26 — исходный запрос: Сделать группы проектов компактными перетаскиваемыми плитками.
- 2026-09-26 — уточнение: карточки самих проектов не должны растягиваться или
  менять привычный размер; на присланном снимке вся группа и проекты заняли
  ширину страницы.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [x] Плитки групп перетаскиваются и сохраняют порядок между проектами.
- [x] Карточки проектов не растягиваются на всю ширину.
- [x] Результат задачи получен и проверен.
- [x] Выводы и проблемы описаны.
- [x] Глобальные знания и решения обновлены.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Ввести один порядок корневых плиток для проекта и группы.
2. Изменить сетку и перенос без изменения карточки проекта.
3. Проверить серверное сохранение, экран и регрессии.
4. Обновить документацию.

## Допущения и ограничения

- Существующие группы и составы проектов не мигрируются и не удаляются.
- Сворачивание остаётся отдельным пользовательским состоянием.

## Уточнения наследуемого контекста

- Если задача дочерняя, перечислите только уточнения и допустимые
  переопределения. Остальной контекст читается из задач-предков.

## Рассмотренные варианты и обоснования

Один общий порядок `position` используется только у корневых карточек и групп.
Внутри группы сохраняется независимый порядок проектов. Это не требует новой
таблицы или миграции пользовательских проектов. Полноширинные секции отвергнуты:
они уводят соседние карточки вниз и нарушают запрос о папках-плитках.

[модель данных](../../knowledge/baza_dannyh_planirovschika.md).
