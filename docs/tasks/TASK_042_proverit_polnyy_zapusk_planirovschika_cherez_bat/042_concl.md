# Выводы TASK_042 — Проверить полный запуск планировщика через bat

[← К описанию](./042_descr.md) · [Журнал](./042_logs.md)

## Краткий итог

Штатный запуск проверен с нуля и работает: `.bat` поднимает API на `8100` и
интерфейс на `3000`, а браузер после перезагрузки отображает реальные данные.

## Подтверждённые результаты и доказательства

- Перед проверкой были остановлены только процессы планировщика на `3000` и
  `8100`.
- Вызов `Запустить планировщик.bat` поднял новые слушающие процессы на обоих
  портах; `scripts/wait_for_planner.py` подтвердил их доступность.
- Страница `http://127.0.0.1:3000/` после перезагрузки показала 20 задач и
  недельное расписание, без `Failed to fetch`.

## Полезные наблюдения

- Проверка запуска должна включать полный перезапуск и проверку данных в
  браузере, а не только код HTTP-ответа.

## Проблемы и преграды

- Неподходящий формат строк `.bat` был причиной предыдущей нестабильности.

## Как решались проблемы

- Добавлен `.gitattributes` с правилом `*.bat text eol=crlf`, закрепляющий
  нужный формат строк при операциях Git.

## Открытые вопросы

- Нет.

## Влияние на глобальное состояние

  страница [архитектуры бэкенда](../../knowledge/arhitektura_bekenda.md)
