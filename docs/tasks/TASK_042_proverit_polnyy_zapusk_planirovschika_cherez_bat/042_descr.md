# TASK_042 — Проверить полный запуск планировщика через bat

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./042_logs.md)
- [Выводы](./042_concl.md)

## Цель

Проверить штатный запуск планировщика с полностью остановленными процессами:
`.bat` должен поднять API, интерфейс и показать реальные данные в браузере.

## Границы

### Входит

- Остановка только процессов планировщика, занявших порты `3000` и `8100`.
- Запуск строго через `Запустить планировщик.bat`.
- Проверка API, интерфейса и отображения данных после перезагрузки страницы.

### Не входит

- Изменение пользовательских данных и остановка посторонних процессов.

## Требования пользователя

- 2026-09-14 — пользователь указал, что предыдущая проверка не доказывала
  полноценный запуск и потребовал проверить `.bat` с нуля.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [x] Старые процессы планировщика остановлены, а новый запуск выполнен через `.bat`.
- [x] API и интерфейс ответили после запуска.
- [x] Браузер после перезагрузки отобразил 20 задач и недельное расписание.
- [x] Установлена защита CRLF-формата для пакетных файлов.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Зафиксировать порты процессов планировщика.
2. Остановить их и вызвать `.bat` как единственный способ запуска.
3. Проверить готовность API и интерфейса, затем перезагрузить интерфейс.
4. Защитить формат пакетного файла и задокументировать доказательства.

## Допущения и ограничения

- Проверяется текущая база `artifacts/database/planner.sqlite3`; пользовательские
  записи не изменяются.

## Уточнения наследуемого контекста

- Если задача дочерняя, перечислите только уточнения и допустимые
  переопределения. Остальной контекст читается из задач-предков.

## Рассмотренные варианты и обоснования

- Проверка только HTTP-ответа недостаточна: критерий включает визуальную
  перезагрузку страницы и наличие реальных задач.
- `.gitattributes` фиксирует CRLF для всех `.bat`, чтобы Git не мог вернуть
  неподходящий формат при будущих операциях с рабочей копией.
