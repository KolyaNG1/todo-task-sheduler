# TASK_048 — Расширить и синхронизировать шкалу итогов

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./048_logs.md)
- [Выводы](./048_concl.md)

## Цель

Сделать сравнительную шкалу факта и плана полностью обозримой с 06:00 до 24:00,
но при открытии сразу показывать рабочую область от 09:00.

## Границы

### Входит

- Постоянный диапазон шкалы 06:00–24:00 независимо от наличия блоков.
- Общая вертикальная прокрутка оси, фактической и плановой колонок.
- Начальное положение прокрутки на отметке 09:00.
- Проверка верхней, начальной и нижней границы в браузере.

### Не входит

- Изменение данных сессий, плановых блоков и расчёта дневных показателей.

## Требования пользователя

- 2026-09-19 — дать возможность прокручивать шкалу с 06:00 до 24:00.
- 2026-09-19 — при открытии показывать время начиная с 09:00.
- 2026-09-19 — факт и план должны прокручиваться синхронно.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [x] Шкала содержит часовые отметки от 06:00 до 24:00.
- [x] При открытии верхняя видимая отметка находится у 09:00.
- [x] Ось, факт и план прокручиваются одним общим движением.
- [x] Результат задачи получен и проверен в браузере.
- [x] Выводы и проблемы описаны.
- [x] Глобальные знания и решения обновлены.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Зафиксировать постоянные границы 06:00–24:00.
2. Обернуть обе колонки и ось времени в один вертикальный контейнер.
3. После отрисовки установить положение контейнера на 09:00.
4. Проверить прокрутку и обновить документацию.

## Допущения и ограничения

- Синхронность обеспечивается одним контейнером прокрутки, а не обменом
  событиями между двумя независимыми полосами.

## Уточнения наследуемого контекста

- Изменяется только сравнительная шкала раздела «Итоги»; недельная навигация из
  родительской задачи остаётся без изменений.

## Рассмотренные варианты и обоснования

- Один общий прокручиваемый контейнер выбран вместо программного связывания двух
  полос: он исключает даже кратковременное расхождение колонок.
