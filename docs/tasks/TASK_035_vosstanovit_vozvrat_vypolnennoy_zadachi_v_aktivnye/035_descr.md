# TASK_035 — Восстановить возврат выполненной задачи в активные

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./035_logs.md)
- [Выводы](./035_concl.md)

## Цель

Дать пользователю один и тот же доступный способ вернуть выполненную задачу в
активные из списка и из её блока в расписании.

## Границы

### Входит

- Кнопка возврата в активные в выполненном блоке календаря.
- Проверка связки кнопки с существующим маршрутом повторного открытия.
- Исправление устаревшей подсказки о сроке повторяющейся задачи.

### Не входит

- Изменение правил повторения задач или переноса срока вручную.

## Требования пользователя

- 2026-09-12 — исходный запрос: Восстановить возврат выполненной задачи в активные.


## Критерии завершения

- [x] Галочка возврата есть на выполненном блоке календаря.
- [x] Она вызывает тот же маршрут, что и кнопка в карточке задачи.
- [x] Документация обновлена и проверена.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Найти различие действий завершённого блока и карточки.
2. Добавить действие возврата в блок.
3. Проверить отображение в свежей вкладке.
4. Зафиксировать результат.

## Допущения и ограничения

- Серверный маршрут повторного открытия из TASK_034 корректен; проблема была
  только в отсутствии кнопки на календарном блоке.

## Уточнения наследуемого контекста

- Если задача дочерняя, перечислите только уточнения и допустимые
  переопределения. Остальной контекст читается из задач-предков.

## Рассмотренные варианты и обоснования

- Использован существующий `reopen-task`, чтобы список, календарь, уведомления
  и сессии не получили отдельные расходящиеся варианты возврата.
