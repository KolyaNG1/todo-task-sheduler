# Выводы TASK_051 — Оценить будущую синхронизацию с Google Календарём

[← К описанию](./051_descr.md) · [Журнал](./051_logs.md)

## Краткий итог

Будущая синхронизация с Google Календарём осуществима без переписывания ядра
планировщика. Безопасный первый этап — импорт внешних событий как занятого
времени только для чтения; экспорт собственных блоков следует делать в
отдельный календарь. Двусторонний обмен — отдельная следующая задача.

## Подтверждённые результаты и доказательства

- **Подтверждено:** `PlannerService` уже изолирует правила календаря от HTTP и
  SQLite, а `FixedEventRule`, `ScheduleBlock` и таблица исходящих событий дают
  естественные точки подключения внешнего адаптера.
- **Подтверждено:** Google Calendar API поддерживает пользовательское
  разрешение через OAuth 2.0, начальную и добавочную синхронизацию по маркеру
  синхронизации, а также уведомления об изменениях. См. [SRC_002](../../sources/SRC_002_google_calendar_api.md).
- **Подтверждено:** мгновенные уведомления требуют доступного из интернета
  HTTPS-адреса; локальное приложение может синхронизироваться вручную или при
  открытии без такого адреса.

## Полезные наблюдения

- У локальных фиксированных событий нет полей для связи с внешним событием,
  календарём, версией или удалением. Их нужно добавить отдельными таблицами,
  не перегружая базовые правила фиксированных событий.
- Секреты и обновляемые ключи доступа не должны попадать в переносимый каталог
  артефактов согласно DEC_003.

## Проблемы и преграды

- Двусторонний обмен без политики «кто является источником истины» и экрана
  разрешения конфликтов небезопасен.
- В текущем локальном запуске невозможны надёжные входящие уведомления Google.

## Как решались проблемы

- Выбрана поэтапная модель: сначала импорт занятости только для чтения,
  затем экспорт в отдельный календарь; двусторонний обмен — только после
  отдельного проектирования конфликтов и удаления событий.

## Открытые вопросы

- Какие календари и направления обмена нужны пользователю: только импорт,
  только экспорт или оба?
- Нужна ли синхронизация в фоне после закрытия локального приложения?
