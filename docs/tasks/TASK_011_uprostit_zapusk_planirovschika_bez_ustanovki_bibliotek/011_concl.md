# Выводы TASK_011 — Упростить запуск планировщика без установки библиотек

[← К описанию](./011_descr.md) · [Журнал](./011_logs.md)

## Краткий итог

Запускатор сокращён до прямого запуска сервера, интерфейса и браузера. Он не
создаёт среду и не выполняет установку пакетов.

## Подтверждённые результаты и доказательства

- **Подтверждено:** `Запустить планировщик.bat` использует установленный в
  системе `python`, запускает Uvicorn на 8000 и статический интерфейс на 5173.
- **Проверка:** команды `python -m uvicorn` и `python -m http.server` уже
  используются работающими локальными сервисами.

## Полезные наблюдения

- Самый короткий запускатор не обязан решать установку зависимостей: это
  отдельная подготовка окружения, от которой пользователь отказался.

## Проблемы и преграды

- На чистом компьютере без подготовленного Python и библиотек файл покажет
  ошибку в минимизированном окне; это сознательный компромисс ради простоты.

## Как решались проблемы

- Выбран прямой запуск без проверки портов и без фоновой установки пакетов.
