# TASK_011 — Упростить запуск планировщика без установки библиотек

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./011_logs.md)
- [Выводы](./011_concl.md)

## Цель

Убрать из запускающего файла создание окружения и установку библиотек, оставив
только команды запуска API, интерфейса и открытия браузера.

## Границы

### Входит

- Упрощённый `Запустить планировщик.bat` без скачивания и установки.
- Обновлённая краткая инструкция.

### Не входит

- Автоматическая подготовка Python или зависимостей на новом компьютере.

## Требования пользователя

- 2026-09-09 — исходный запрос: Упростить запуск планировщика без установки библиотек.
- 2026-09-09 — пользователь явно отказался от `venv`, скачивания библиотек и
  сложной логики: нужны лишь несколько команд запуска.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [x] Запускаемый файл содержит только запуск двух серверов и открытие браузера.
- [x] Результат задачи получен и проверен.
- [x] Выводы и проблемы описаны.
- [x] Глобальные знания обновлены.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Удалить подготовку окружения и установку из запускающего файла.
2. Сохранить три прямых действия запуска.
3. Проверить доступность команд в текущем окружении.
4. Обновить документацию.

## Допущения и ограничения

- Python с уже установленными FastAPI, Uvicorn и SQLAlchemy доступен в `PATH`.

## Уточнения наследуемого контекста

- Если задача дочерняя, перечислите только уточнения и допустимые
  переопределения. Остальной контекст читается из задач-предков.

## Рассмотренные варианты и обоснования

Сохраняйте краткие причины выбора, альтернативы и проверяемые допущения, но не
скрытое пошаговое рассуждение модели.
