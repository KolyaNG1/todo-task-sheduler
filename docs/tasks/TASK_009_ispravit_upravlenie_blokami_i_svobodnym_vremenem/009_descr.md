# TASK_009 — Исправить управление блоками и свободным временем

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./009_logs.md)
- [Выводы](./009_concl.md)

## Цель

Сделать недельный план предсказуемым при ручном управлении: удалять отдельные
интервалы свободного времени, безопасно переносить один выбранный блок и
управлять блоком непосредственно на сетке.

## Границы

### Входит

- Кнопка удаления для каждого видимого интервала свободного времени.
- Устойчивое перетаскивание: один перенос меняет только выбранный блок.
- Действия блока плана: запуск работы, изменение времени и снятие с плана.
- Серверная проверка 15-минутной сетки для новых и изменяемых блоков.

### Не входит

- Удаление самой задачи из списка задач: снятие с плана сохраняет задачу.

## Требования пользователя

- 2026-09-09 — исходный запрос: Исправить управление блоками и свободным временем.
- 2026-09-09 — пользователь сообщил, что свободное время всё ещё нельзя удалить,
  при переносе один блок иногда дёргает блоки других дней, а у блоков плана нет
  удаления и нужных действий.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [x] Сетка даёт удалить отдельный интервал свободного времени.
- [x] Перенос изменяет только перетаскиваемый блок и сохраняет его длительность.
- [x] Блок плана содержит доступные действия запуска, изменения и снятия с плана.
- [x] Результат задачи получен и проверен.
- [x] Выводы и проблемы описаны.
- [x] Глобальные знания обновлены.
- [ ] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Проверить текущие обработчики сетки и жизненный цикл блока.
2. Добавить явные действия интервалов и блоков.
3. Отвязать перенос от неоднозначного состояния браузерного события.
4. Проверить серверные сценарии, клиентский код и страницу в браузере.
5. Обновить документацию.

## Допущения и ограничения

- Снятие блока с плана отменяет только его размещение, не удаляя задачу.

## Уточнения наследуемого контекста

- Если задача дочерняя, перечислите только уточнения и допустимые
  переопределения. Остальной контекст читается из задач-предков.
