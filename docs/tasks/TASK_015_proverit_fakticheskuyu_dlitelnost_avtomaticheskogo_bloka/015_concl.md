# Выводы TASK_015 — Проверить фактическую длительность автоматического блока

[← К описанию](./015_descr.md) · [Журнал](./015_logs.md)

## Краткий итог

Автоматическое распределение сохраняет заданную оценку задачи, не уменьшая её до ближайшего шага сетки.

## Подтверждённые результаты и доказательства

- **Подтверждено:** задача без разрешения деления получает цельный блок своей оставшейся оценки либо не размещается.
- **Подтверждено:** для задачи с разрешением деления сначала выбирается цельное окно, если оно есть; дефицит менее 30 минут остаётся отдельным конфликтным блоком.
- **Доказательство:** `python -m pytest tests -q` в `backend` завершён успешно: 8 тестов.

## Полезные наблюдения

- Шаг сетки не должен округлять оценку задачи вниз: сетка отвечает за выбор позиции на расписании, а оценка хранится в минутах.

## Проблемы и преграды

- Первоначальное округление длительности вниз могло уменьшить фактический блок.

## Как решались проблемы

- Округление длительности исключено из алгоритма; флаг `can_split` определяет допустимость деления.
