# TASK_014 — Исправить длительность автоматического распределения

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./014_logs.md)
- [Выводы](./014_concl.md)

## Цель

Сделать оценку времени задачи целевой длительностью автоматического блока, а
15-минутную сетку оставить только шагом времени, не размером блока.

## Границы

### Входит

- Цельный автоматический блок для обычной задачи.
- Явный флажок разрешения разбивать задачу в форме.
- Серверная проверка длительности блоков.

### Не входит

- Перераспределение уже подтверждённых блоков пользователя.

## Требования пользователя

- 2026-09-09 — исходный запрос: Исправить длительность автоматического распределения.
- 2026-09-09 — пользователь сообщил, что автоматический план всегда создаёт
  15-минутные части вместо указанной длительности задачи.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [x] Обычная задача размещается целым блоком на её оценку.
- [x] Дробление доступно только при явном разрешении и по размеру блока задачи.
- [x] Результат задачи получен и проверен.
- [x] Выводы и проблемы описаны.
- [x] Глобальные знания обновлены.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Проверить расчёт длительности в планировщике.
2. Отделить шаг сетки от размера блока.
3. Добавить выбор дробления и проверки.
4. Перезапустить сервер и обновить документацию.

## Допущения и ограничения

- 15 минут — дискретность времени, а не значение по умолчанию для длительности.

## Уточнения наследуемого контекста

- Если задача дочерняя, перечислите только уточнения и допустимые
  переопределения. Остальной контекст читается из задач-предков.

## Рассмотренные варианты и обоснования

Сохраняйте краткие причины выбора, альтернативы и проверяемые допущения, но не
скрытое пошаговое рассуждение модели.
