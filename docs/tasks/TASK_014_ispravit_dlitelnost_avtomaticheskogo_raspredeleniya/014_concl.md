# Выводы TASK_014 — Исправить длительность автоматического распределения

[← К описанию](./014_descr.md) · [Журнал](./014_logs.md)

## Краткий итог

Автоматическое распределение использует указанную оценку как длительность
обычного блока. Шаг 15 минут применяется только к границам времени.

## Подтверждённые результаты и доказательства

- **Подтверждено:** новые задачи создаются без дробления; форма позволяет
  включить его явно.
- **Подтверждено:** планировщик не создаёт произвольные 15-минутные части
  задачи только потому, что в окне осталось 15 минут.
- **Проверка:** `pytest backend/tests -q` — 7 успешных проверок; API после
  перезапуска ответил `200`.

## Полезные наблюдения

- Дискретность сетки и размер рабочего блока — разные правила модели.

## Проблемы и преграды

- Уже подтверждённые блоки не меняются автоматически. Старую задачу можно
  снять с плана и запланировать заново.

## Как решались проблемы

- Обычная задача требует непрерывный блок своей оценки; дробление возможно
  только при явном флажке.
