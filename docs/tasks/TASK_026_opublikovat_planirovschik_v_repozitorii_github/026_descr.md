# TASK_026 — Опубликовать планировщик в репозитории GitHub

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./026_logs.md)
- [Выводы](./026_concl.md)

## Цель

Опубликовать текущий проект в репозитории пользователя: полный исходный код и
документацию поместить в ветку `MVP`, а в `main` добавить краткий README со
ссылкой на ветку MVP. Пользовательские базы данных и другие изменяемые локальные
данные в удалённый репозиторий не отправлять.

## Границы

### Входит

- Инициализация локальной истории Git и настройка удалённого репозитория.
- Публикация исходников и документации в `MVP`.
- Добавление README в `main`.

### Не входит

- Публикация файлов баз данных, резервных копий, журналов и иных локальных
  изменяемых данных.

## Требования пользователя

- 2026-09-11 — исходный запрос: Опубликовать планировщик в репозитории GitHub.
- 2026-09-11 — уточнение: отправить всё сразу, но не отправлять пользовательскую
  базу данных.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [ ] Ветка `MVP` содержит проект без пользовательской базы данных.
- [ ] Ветка `main` содержит README с описанием и ссылкой на `MVP`.
- [ ] Удалённые ветки проверены после отправки.
- [ ] Выводы и проблемы описаны.
- [ ] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Уточнить область и существующие знания.
2. Выполнить работу или исследование.
3. Проверить результат.
4. Обновить локальную и глобальную документацию.
