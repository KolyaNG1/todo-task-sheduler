# TASK_047 — Стабилизировать недельную навигацию итогов

[← К дашборду](../../TASKS_DASHBOARD.md)

## Навигация

- [Журнал](./047_logs.md)
- [Выводы](./047_concl.md)

## Цель

Заменить плавающую ленту последних дней на устойчивую недельную навигацию
Пн–Вс, чтобы выбор дня не сдвигал и не скрывал соседние даты.

## Границы

### Входит

- Ровно семь карточек выбранной недели от понедельника до воскресенья.
- Текущая неделя при первом открытии итогов и по кнопке возврата.
- Переключение на предыдущую и следующую неделю без горизонтального накопления.
- Приглушённое отображение ещё не наступивших дат.
- Согласование выбранного дня, поля даты и недельной ленты.
- Программная и визуальная проверка.

### Не входит

- Изменение расчёта дневных показателей и структуры сохранённых снимков.
- Бесконечная горизонтальная прокрутка календаря итогов.

## Требования пользователя

- 2026-09-19 — вместо сдвигающейся ленты последних дней всегда показывать одну
  неделю Пн–Вс.
- 2026-09-19 — будущие дни недели отображать серыми.
- 2026-09-19 — добавить переключатель недель и при открытии показывать текущую
  неделю.

Добавляйте сюда каждое существенное уточнение пользователя с датой.

## Критерии завершения

- [x] Выбор дня не меняет состав семи карточек его недели.
- [x] Переключатели недель сохраняют тот же день недели и показывают Пн–Вс.
- [x] Текущая неделя открывается по умолчанию и восстанавливается отдельной
  кнопкой.
- [x] Будущие даты визуально приглушены.
- [x] Результат задачи получен и проверен в браузере.
- [x] Выводы и проблемы описаны.
- [x] Глобальные знания и решения обновлены.
- [x] `python scripts/docs_ctl.py check` завершился без ошибок.

## План

1. Отделить начало отображаемой недели от выбранной даты отчёта.
2. Загружать историю строго за Пн–Вс и дополнять отсутствующие дни пустыми
   карточками.
3. Добавить недельные переключатели и стили будущих дней.
4. Проверить переходы между днями и неделями в браузере.
5. Обновить документацию.

## Допущения и ограничения

- Неделя начинается в понедельник согласно русскому календарю.
- При переключении недели сохраняется выбранный день недели: например, среда
  переходит в среду соседней недели.

## Уточнения наследуемого контекста

- Недельная навигация относится только к экрану «Итоги» и не меняет диапазон
  основной сетки расписания.

## Рассмотренные варианты и обоснования

- Отдельная переменная начала недели предотвращает прежний эффект, когда
  диапазон истории вычислялся от каждого выбранного дня и необратимо «уезжал».
- Семь фиксированных карточек лучше бесконечной прокрутки: вся неделя всегда
  обозрима, а переход между неделями остаётся явным.
