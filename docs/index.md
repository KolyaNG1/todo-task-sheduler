## Работа с задачами

- Новая глобальная цель или исследование получает отдельную папку задачи.
- Создание: `python scripts/docs_ctl.py create "Название задачи"`.
- Создание задачи проекта: `python scripts/docs_ctl.py create "Название задачи"
  --project <project_id>`.
- Создание дочерней задачи: добавьте `--parent TASK_NNN`.
- Создание связанной задачи: добавьте `--related TASK_NNN`.
- Зависимость или замена: `--depends-on TASK_NNN` либо
  `--supersedes TASK_NNN`.
- Просмотр наследуемого контекста: `python scripts/docs_ctl.py context TASK_NNN`.
- Регистрация проекта: `python scripts/docs_ctl.py add-project <путь>
  "Название"`.
- Синхронизация: `python scripts/docs_ctl.py sync`.
- Полная проверка: `python scripts/docs_ctl.py check`.
- Экспорт чистой основы: `python scripts/docs_ctl.py export-template <каталог>`.

Шаблоны находятся в [каталоге шаблонов](templates/index.md).
